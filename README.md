# ארקייד המספרים של אלון – V17

V17 מבוססת על V16 ומוסיפה שני שיפורים:

## דגים מספרים
כבר לא לוחצים על הדג.
- יש חכה, חוט וקרס.
- גוררים את הקרס באצבע/עכבר עד לדג.
- רק מגע של הקרס בדג בודק את התשובה.
- דג נכון נלכד ועולה עם החכה.
- דג לא נכון משתחרר והמספר המבוקש נשאר.

## דינו המספרים
משחק ריצה בסגנון משחק הדינוזאור של הדפדפן:
- הדינוזאור רץ אוטומטית.
- מספרים בתוך ביצים מגיעים מצד המסך.
- המספר שצריך למצוא מופיע בגדול למעלה.
- מקישים על המסלול כדי לקפוץ בזמן שהמספר הנכון מגיע לדינוזאור.
- 5 תפיסות נכונות מסיימות סיבוב.
