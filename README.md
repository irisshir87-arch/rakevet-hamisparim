# ארקייד המספרים של אלון – V19

V19 מבוססת על V18 ומוסיפה את **חייזרי המספרים**.

## חייזרי המספרים 👽
- לוח 6×6 של חייזרים עם ספרות.
- לוחצים על שני חייזרים סמוכים כדי להחליף ביניהם.
- 3 חייזרים זהים בשורה או בטור נעלמים.
- המספר המבוקש מופיע בגדול למעלה.
- התאמה של מספר המטרה מקדמת את המשימה.
- 4 ברצף מפעיל לייזר שמנקה שורה או טור.
- 5 ברצף מפעיל חללית שמנקה את כל החייזרים עם אותה ספרה.
- חייזרים חדשים ממלאים את הלוח אחרי כל התאמה.
- צבעי החייזרים אקראיים ואינם קבועים לפי הספרה.
- אחרי 5 התאמות נכונות מסיימים.
