- המכונית נוסעת כל הזמן במסלול עם 3 נתיבים.
- עוברים נתיב בלחיצה, בחיצים או בהחלקה.
- מכשולים כמו 🚧 🪨 🛢️ יורדים במסלול וצריך להתחמק מהם.
- מספרים יורדים במסלול בתוך כוכבים.
- אוספים רק את המספר שמופיע במשימה למעלה.
- מספר נכון נותן בוסט ומחליף למשימה חדשה.
- פגיעה במכשול עושה 💥 קטן אבל אין Game Over.
- אחרי 5 מספרים נכונים מגיעים לסיום.

## סנייק המספרים
- משחק בסגנון Snake של נוקיה.
- הנחש זז ברצף.
- שולטים עם חצים או החלקה על הלוח.
- צריך לאכול את המספר שמופיע במשימה.
- מספר נכון מאריך את הנחש ומחליף משימה.
- בקצה הלוח הנחש עובר לצד השני, כדי לא לתסכל ילד בן 4.
- התנגשות בעצמו לא מסיימת את המשחק.
- אחרי 5 מספרים נכונים מסיימים.
